# 1<sup>er</sup> Parcial de Programación IV

El primer parcial se tomará el miércoles 30 de septiembre.

Será un examen de opción múltiple y deberá resolverse desde el celular o una computadora en clase.

El examen constará de 50 preguntas para responder en 1 hora. Cada alumno podrá realizar hasta 3 intentos.

Las preguntas se elegirán al azar a partir de una base de preguntas y se basarán estrictamente en el contenido de los apuntes de la materia.

Dispondrá de las preguntas sin respuestas para estudiar. Además, contará con una página que le permitirá reforzar y recordar el material mediante el método de repetición espaciada: [Aprender aquí](https://tup26-p4-parcial.netlify.app).

También existe una [versión imprimible](./1parcial-imprimir.pdf) de las preguntas si lo prefiere.

Los apuntes en los que se basan las preguntas están en la [carpeta de apuntes](./apuntes), y también puede acceder a los mismos en formato de libro para facilitar la lectura: [Leer en PDF](./apuntes-completos.pdf) o [Leer en EPUB](./apuntes-completos.epub).
