Arreglos: datos por posición

Una colección ordenada, numerada desde cero, que crece y se achica. Puede mezclar tipos, aunque normalmente conviene mantener elementos homogéneos.

La pregunta que responde

“¿Cuál es el tercero?” El orden es parte del significado.

const nombres = ["Ana", "Luis", "Sol"];
nombres[0];       // "Ana"
nombres.at(-1);   // "Sol"
nombres[99];      // undefined

const permite agregar elementos: congela la referencia, no el contenido. Array.isArray() distingue un arreglo de otros objetos.

Explorador de índices

Hacé clic en una celda para leer su índice.

La trampa de fill

Modo peligroso: las tres posiciones apuntan a la misma fila. Tocá una celda.

¿Por qué ocurre?

new Array(3).fill([0,0,0]) repite la misma referencia. Cambiar una “fila” cambia el único arreglo compartido.

// Correcto: crea una fila nueva por vuelta
const buena = Array.from(
  { length: 3 },
  () => new Array(3).fill(0)
);

Recorrer un objeto
Un objeto común no es iterable. Convertí con Object.keys, Object.values u Object.entries.
for (const [clave, valor] of Object.entries(contacto)) {
  console.log(`${clave}: ${valor}`);
}
