Atajos

    
Pensada para dar clase: letra grande, resultados pegados a su línea y nada que distraiga.

    

      
Ctrl + EnterEjecutar el código

      
Ctrl + /Comentar o descomentar las líneas seleccionadas

      
Tab / Shift + TabIndentar o sacar indentación

      
Ctrl + + / Ctrl + −Agrandar o achicar la letra

      
Ctrl + 0Volver al tamaño de clase

      
Ctrl + SGuardar el código como archivo .js

      
Ctrl + MPasar el código a Markdown

      
Clic en un resultadoDesplegarlo completo

      
Arrastrar un .jsCargarlo en el editor
