function duplicar(valor) {
  return valor * 2;
}

// Las anotaciones ya no existen.
¿Entonces TypeScript valida una respuesta de una API?

No. Una interfaz expresa lo que el programa espera, pero los datos externos deben comprobarse durante la ejecución. Los tipos estáticos y la validación protegen problemas distintos.
