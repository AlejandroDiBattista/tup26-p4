# Aforo · Conteo de tránsito

Contador de motos, autos y camionetas con cronómetro, flujo en vehículos por hora, pausas, guardado local y exportación CSV.

```sh
npm install
npm run dev
```

Construido con React, TypeScript, Vite, Tailwind 4 y shadcn/ui. Consultar [instrucciones.md](./instrucciones.md) para el uso, el cálculo del flujo y las pruebas.
