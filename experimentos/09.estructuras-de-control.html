Del laberinto a las guardas

Un retorno temprano separa cada impedimento y deja el camino principal alineado a la izquierda.

Misma regla, distinta forma legibilidad
Anidamiento
if (usuario) {
  if (usuario.activo) {
    if (carrito.length) {
      return confirmar();
    } else {
      return "carrito vacío";
    }
  } else {
    return "inactivo";
  }
}
Guardas
if (!usuario) {
  return "falta usuario";
}
if (!usuario.activo) {
  return "inactivo";
}
if (carrito.length === 0) {
  return "carrito vacío";
}

return confirmar();
¿Retornar un resultado o lanzar una excepción?

Una alternativa normal del negocio suele devolverse. Si la función no puede cumplir su contrato —por ejemplo, recibe un tipo incompatible— puede lanzar una excepción.
