La estructura del MiniCRM

El cliente es el dueño de sus actividades. La relación es de composición: sus actividades dependen de él para existir.

Las fechas tienen distintos propósitos

fecha
Fecha indicada para la actividad; puede no conocerse.
fechaCompromiso
Día previsto para realizar la tarea.
completadaEn
Instante en que se marca como completada. Drizzle lo maneja como Date y SQLite guarda milisegundos.

El estado se deduce de las fechas

Pendiente: completadaEn = null.

Completada: tiene fecha y hora en completadaEn.

Vencida: pendiente con compromiso anterior a hoy.

Sin compromiso: pendiente con fechaCompromiso = null.

Todos los listados de actividades requieren el clienteId.

Modelo definido en schema.ts · Validaciones de clientes en repositorios/clientes.ts · Diagrama estático para la clase.
