01

La variable es una flecha

En JavaScript el nombre no tiene tipo. El tipo pertenece al valor, y la variable es una etiqueta que puede apuntar a distintos valores.

Modelo mental

No imagines una caja con algo adentro. Imaginá una flecha que une un nombre con un valor en memoria.

let dato = 42;
dato = "cuarenta";
dato = true;

En C# escribirías int edad: el nombre y el tipo quedan unidos. En JavaScript, dato puede cambiar incluso de tipo.

dato
42 · number
"cuarenta" · string
true · boolean
02

Tres formas de declarar

var es historia. const es el punto de partida. let aparece cuando necesitás reasignar.

Comparación rápida

constbloqueerrornonoobligatoria

var

No respeta bloques, permite redeclarar y antes de su línea vale undefined por hoisting.

Aprendelo para leer código viejo. No lo uses.

let

Respeta el bloque, no permite redeclarar y vive en zona muerta temporal hasta su declaración.

Usalo si el nombre debe apuntar a otro valor.

const

Congela la referencia, no el contenido. Un objeto declarado con const todavía puede cambiar por dentro.

Usalo por defecto.

Alcance: desde adentro se ve hacia afuera

El motor busca el nombre en el bloque actual y sube por la cadena de alcances. Si un nombre se repite, gana el más cercano: eso es sombreado.

Globalconst nivel1 = "global";
Funciónconst nivel2 = "función";
Bloqueconst nivel3 = "bloque";
Acá se ven los tres niveles.

¿const significa inmutable?

const contacto = { nombre: "Ana" };
contacto.nombre = "Luis"; // ✓
contacto.email = "l@mail.com"; // ✓
contacto = {};                 // ✗ TypeError

Las dos primeras operaciones modifican el objeto. La última intenta mover la flecha.

Inspector de nombres

Letras, _ o $ al inicio; después también dígitos.
✓ Nombre válido y en camelCase.

typeof: útil, con dos rarezas

Array.isArray([1, 2]); // true

typeof null; // "object" ← error de 1995
typeof function() {}; // "function"

Por valor vs. por referencia

Primitivo: se copia el valor. Cada variable queda independiente.

Objeto: se copia la referencia. Ambas variables apuntan al mismo objeto.

const original = { nombre: "Ana" };
const copia = original;
copia.nombre = "Luis";
// original.nombre también es "Luis"

04

Booleanos y decisiones

Cuando JavaScript espera un booleano, convierte. La lista de valores falsy es corta; todo lo demás es truthy.

Los ocho falsy

false0-00n""nullundefinedNaN

Todo lo demás es truthy, incluidos "0", "false", [] y {}.

La regla de comparación

Usá === y !==. La igualdad débil == convierte antes de comparar y produce sorpresas.

1 === "1"; // false
1 == "1";  // true ← convirtió

|| versus ??

Los operadores && y || devuelven uno de sus operandos y cortan la evaluación. Para valores por defecto, la diferencia entre || y ?? importa.

05

Un solo tipo numérico

number usa punto flotante IEEE 754 de 64 bits. Es simple, rápido y tiene límites que conviene conocer.

El decimal imposible

Algunos decimales no tienen representación binaria exacta.

0.1 + 0.2 = 0.30000000000000004

Para plata: enteros

Guardá centavos, no decimales. 1050 representa $10,50. Para enteros mayores a Number.MAX_SAFE_INTEGER, existe bigint.

const grande = 9007199254740993n;
grande + 1n; // ✓
grande + 1;  // TypeError

Infinity

1 / 0 no lanza excepción: devuelve Infinity.

NaN

No es igual a sí mismo. Detectalo con Number.isNaN(), no con la función global.

32 bits

Los operadores de bits convierten a entero de 32 bits. Usalos para máscaras y permisos, no para truncar.

06

Cadenas: texto inmutable

Comillas simples, dobles o invertidas producen string. Las invertidas agregan interpolación y múltiples líneas.

Plantillas de texto

const nombre = "Ana";
const edad = 30;

const mensaje =
  `Hola ${nombre}, tenés ${edad} años`;

Dentro de ${…} puede ir cualquier expresión: cálculos, ternarios o acceso opcional.

Inmutable no significa inútil

let saludo = "hola";
saludo[0] = "H"; // no cambia nada
saludo = saludo.toUpperCase();
// ahora apunta a una cadena nueva

Conversión de tipos

tipo: number

La regla especial de +

Si algún operando es cadena, concatena. Los demás operadores aritméticos convierten a número.

"5" + 3;     // "53"
"5" - 3;     // 2
1 + 2 + "3"; // "33"
"1" + 2 + 3; // "123"

El formulario siempre entrega texto

const cantidad = "3";
const precio = "100";

cantidad * precio; // 300, de casualidad
cantidad + precio; // "3100"

Number(cantidad) * Number(precio); // 300 ✓

08

Lo que te llevás

Si estas reglas quedan claras, desaparece buena parte del “JavaScript hace cosas raras”.

01. La variable apunta; el valor tiene el tipo.
02. const por defecto, let si reasignás, nunca var.
03. const congela la referencia, no el objeto.
04. Primitivos por valor; objetos por referencia.
05. Solo ocho valores son falsy; [] y {} son truthy.
06. Para ausencia usá ??; || reemplaza todo falsy.
07. number es punto flotante; para plata, enteros.
08. Convertí explícitamente y compará con ===.
