# Set

Programación IV: Desarrollo Web — Etapa 1, fundamentos técnicos
Apunte de la tercera clase de JavaScript, 3 de 4

El [arreglo](031-arreglos.md) guarda por posición y el [objeto](032-objetos.md) por nombre. Quedan casos que ninguno de los dos resuelve bien, y para eso están las dos estructuras que agregó ES2015: `Set` y [`Map`](034-map.md).

Un `Set` es una colección de valores sin repetidos y sin claves. Responde una sola pregunta: si un valor está o no está.

## Cómo se crea y se usa

```javascript
const etiquetas = new Set();

etiquetas.add("cliente");
etiquetas.add("activo");
etiquetas.add("cliente");   // ignorado, ya estaba

etiquetas.size;             // 2
etiquetas.has("activo");    // true
etiquetas.delete("activo"); // true, lo eliminó
etiquetas.clear();          // vacía todo
```

Toda la interfaz son esos cinco métodos más `size`. No hay índices, no hay `length`, no se puede pedir "el tercero".

`add` devuelve el mismo `Set`, así que se puede encadenar:

```javascript
const permisos = new Set().add("leer").add("escribir");
```

Se puede crear desde cualquier iterable, y de ahí sale su uso más frecuente:

```javascript
const numeros = [1, 2, 2, 3, 3, 3];
const sinRepetir = [...new Set(numeros)]; // [1, 2, 3]

new Set("hola");             // {"h", "o", "l", "a"}
new Set(mapaDeContactos.keys());
```

Ese `[...new Set(x)]` es el modismo estándar para quitar duplicados de un arreglo. Vale la pena memorizarlo.

## Cómo se recorre

Es iterable, así que se recorre con `for...of` y mantiene el orden en que agregaste los elementos:

```javascript
for (const etiqueta of etiquetas) {
  console.log(etiqueta);
}

etiquetas.forEach((e) => console.log(e));
```

Para volver a arreglo y usar `map`, `filter` y compañía:

```javascript
[...etiquetas];             // arreglo
Array.from(etiquetas);      // lo mismo
[...etiquetas].sort();      // ordenado
```

Un `Set` no tiene `map` ni `filter` propios. La forma de transformarlo es convertirlo a arreglo, operar y volver:

```javascript
const enMayusculas = new Set([...etiquetas].map((e) => e.toUpperCase()));
```

## Cómo compara los valores

La comparación es prácticamente la de `===`, con una excepción: `NaN` sí se considera igual a sí mismo dentro de un `Set`. Esa regla se llama SameValueZero, y también trata a `0` y `-0` como el mismo valor.

```javascript
const s = new Set();
s.add(NaN);
s.add(NaN);
s.size;   // 1, aunque NaN !== NaN
```

Como los objetos se comparan por referencia, dos objetos con el mismo contenido son dos elementos distintos:

```javascript
const s = new Set();
s.add({ a: 1 });
s.add({ a: 1 });
s.size; // 2
```

Esto limita mucho el uso de `Set` con objetos. Si querés eliminar duplicados de una lista de objetos, tenés que elegir una clave y usarla:

```javascript
const contactos = [
  { id: 1, nombre: "Ana" },
  { id: 1, nombre: "Ana" },
  { id: 2, nombre: "Luis" },
];

// Con Set, quedándote solo con la clave
const idsUnicos = new Set(contactos.map((c) => c.id)); // {1, 2}

// Con Map, si querés los objetos completos
const unicos = [...new Map(contactos.map((c) => [c.id, c])).values()];
```

## Por qué existe: la pertenencia

Comparado con un arreglo, `Set` gana cuando la pregunta es la pertenencia.

Buscar en un arreglo con `includes` recorre los elementos uno por uno. En el peor caso los mira todos. En un `Set`, `has` va directo al valor, sin importar cuántos elementos haya.

```javascript
const lista = ["a", "b", "c" /* ... 100000 elementos */];
const conjunto = new Set(lista);

lista.includes("z");    // recorre todo antes de decir que no
conjunto.has("z");      // respuesta inmediata
```

Con diez elementos no se nota. Con diez mil, y adentro de un bucle, la diferencia es de segundos contra milisegundos. El caso típico es filtrar una lista contra otra:

```javascript
// Lento: por cada contacto, recorre todos los ids bloqueados
const permitidos = contactos.filter((c) => !idsBloqueados.includes(c.id));

// Rápido: el Set se arma una vez y cada consulta es directa
const bloqueados = new Set(idsBloqueados);
const permitidos = contactos.filter((c) => !bloqueados.has(c.id));
```

## Operaciones de conjuntos

Desde 2024 los navegadores incorporaron los métodos de la teoría de conjuntos. Reciben otro `Set` y devuelven uno nuevo, sin modificar los originales:

```javascript
const a = new Set([1, 2, 3]);
const b = new Set([3, 4]);

a.union(b);                // {1, 2, 3, 4}
a.intersection(b);         // {3}
a.difference(b);           // {1, 2}
a.symmetricDifference(b);  // {1, 2, 4}

a.isSubsetOf(b);           // false
a.isSupersetOf(new Set([1])); // true
a.isDisjointFrom(b);       // false, comparten el 3
```

Son recientes, así que en entornos viejos hay que hacerlas a mano:

```javascript
const union = new Set([...a, ...b]);
const interseccion = new Set([...a].filter((x) => b.has(x)));
const diferencia = new Set([...a].filter((x) => !b.has(x)));
```

Vale la pena escribir las tres a mano una vez: se entiende mejor qué hace cada una y por qué el `Set` es la estructura natural para esto.

## Casos de uso habituales

Quitar duplicados de una lista:

```javascript
const ciudades = [...new Set(contactos.map((c) => c.ciudad))];
```

Etiquetas o permisos de una entidad, donde solo importa si están:

```javascript
const permisos = new Set(["leer", "escribir"]);
if (permisos.has("borrar")) { /* ... */ }
```

Marcar lo ya procesado, para no repetir trabajo ni entrar en ciclos:

```javascript
const visitados = new Set();

for (const nodo of grafo) {
  if (visitados.has(nodo.id)) continue;
  visitados.add(nodo.id);
  // procesar
}
```

Filtrar una lista contra otra, como vimos arriba.

## Set y WeakSet

Existe una variante, `WeakSet`, que solo acepta objetos y no impide que el recolector de basura los libere. No es iterable ni tiene `size`. Sirve para marcar objetos sin retenerlos en memoria, por ejemplo para recordar cuáles ya se procesaron sin evitar que se descarten.

Es un caso raro en desarrollo web común. Alcanza con saber que existe.

## Cuándo usar Set

| Necesito | Estructura |
|---|---|
| orden y elementos repetidos | [arreglo](031-arreglos.md) |
| propiedades con nombre de una entidad | [objeto](032-objetos.md) |
| saber si un valor está, sin repetidos | `Set` |
| asociar una clave a un valor | [Map](034-map.md) |

Dos límites a tener presentes. Un `Set` no se convierte solo a JSON: `JSON.stringify(new Set([1,2]))` devuelve `{}`, así que hay que pasarlo a arreglo antes de mandarlo por la red. Y no sirve para deduplicar objetos por contenido, por lo que vimos sobre la comparación por referencia.

## Para llevarte

- `Set` guarda valores únicos y responde una sola pregunta: si un valor está
- la interfaz es `add`, `has`, `delete`, `clear` y `size`
- `[...new Set(arreglo)]` es la forma estándar de quitar duplicados
- es iterable y conserva el orden de inserción
- compara con SameValueZero: como `===`, salvo que `NaN` es igual a sí mismo
- los objetos se comparan por referencia, así que no deduplica por contenido
- `has` es inmediato; `includes` de un arreglo recorre todo
- las operaciones de conjuntos ya son métodos, y también se escriben con `filter` y propagación
- no se serializa a JSON: convertilo a arreglo antes
