## 1. ¿Qué es una expresión regular?

Una **expresión regular** (regex) es una secuencia de caracteres que define un **patrón de búsqueda**. No es propia de JavaScript: existe en casi todos los lenguajes (Python, Java, Perl, Go…). En JavaScript es un objeto de primera clase, integrado en el lenguaje desde su creación.

Mentalmente, una regex es como un **colador con forma**: pasas texto por ella y te quedas solo con las porciones que encajan en la forma.

```js
const texto = "Hola mundo";
const patron = /mundo/;

console.log(patron.test(texto)); // true
```

---

## 2. Primer principio: el motor y el texto

El núcleo mental que debes tener claro: una regex **no "entendende" el lenguaje humano**, solo recorre una cadena de izquierda a derecha, carácter por carácter, buscando la **primera posición** donde el patrón pueda coincidir.

- El texto es una **lista ordenada de caracteres** (técnicamente, unidades de código UTF-16).
- El motor intenta hacer *match* empezando en cada posición `0, 1, 2, ...` hasta encontrar una coincidencia o llegar al final.
- Por defecto, **encuentra una sola coincidencia** (la primera). Para buscar todas, usa el flag `g`.

```js
"abcabc".match(/abc/);    // ["abc"]  → solo la primera
"abcabc".match(/abc/g);   // ["abc", "abc"]  → todas
```

---

## 3. Literales y el constructor `RegExp`

Hay dos formas de crear una regex:

### Literal (la más común)

```js
const re1 = /hola/;
```

- Se compila **una vez** (en tiempo de parseo).
- La barra `/` delimita el patrón; los flags van después de la segunda barra.

### Constructor `RegExp`

```js
const re2 = new RegExp("hola");
const re3 = new RegExp("hola", "i"); // con flag
```

- Útil cuando el patrón se construye **dinámicamente** (en runtime).
- El patrón es un **string**, así que hay que escapar la barra invertida dos veces (`\\d` en vez de `\d`).

```js
const palabra = "hola";
const reDinamica = new RegExp(palabra, "i");
```

> Regla: usa el literal siempre que el patrón sea fijo; usa `RegExp` solo cuando necesites construirlo con variables.

## 4. Caracteres simples

El caso más básico: un carácter coincide consigo mismo.

```js
/a/.test("manzana"); // true  (la 'a' está en la posición 1)
```

Una secuencia de caracteres simples los exige **en ese orden consecutivo**:

```js
/casa/.test("barca casita"); // false (no hay "casa" seguido)
/casa/.test("mi casa es grande"); // true
```

---

## 5. Clases de caracteres

Una **clase** (`[...]`) coincide con **un solo** carácter, cualquiera de los listados dentro de los corchetes.

```js
/[aeiou]/.test("rps");   // false
/[aeiou]/.test("perro"); // true ('e')
```

- Rango: `[a-z]`, `[0-9]`, `[A-Za-z0-9]`.
- Negación: `[^...]` coincide con cualquier carácter **excepto** los listados.

```js
/[0-9]/.test("abc3");    // true
/[^0-9]/.test("123");    // false
/[^0-9]/.test("1a2");    // true
```

### Clases predefinidas (atajos)

| Atajo | Equivale a | Significado |
|-------|-----------|-------------|
| `\d`  | `[0-9]`   | dígito |
| `\D`  | `[^0-9]`  | no dígito |
| `\w`  | `[A-Za-z0-9_]` | carácter de "palabra" |
| `\W`  | `[^A-Za-z0-9_]` | no palabra |
| `\s`  | espacio, tab, salto de línea | espacio en blanco |
| `\S`  | lo contrario | no espacio |
| `.`   | cualquier carácter excepto salto de línea | comodín |

```js
/\d\d/.test("a1b2"); // true (encuentra "12")
/\w+/.test("hola_mundo123"); // true
/./.test("\n"); // false (el punto no匹配 saltos de línea sin flag 's')
```

## 6. Anclas: posición, no caracteres

Las anclas **no consumen caracteres**, solo comprueban *dónde* estás en el texto.

| Ancla | Significado |
|-------|-------------|
| `^`   | inicio de la cadena (o de línea con `m`) |
| `$`   | fin de la cadena (o de línea con `m`) |
| `\b`  | límite de palabra (entre `\w` y `\W`) |
| `\B`  | no límite de palabra |

```js
/^hola/.test("hola mundo"); // true (empieza por "hola")
/^hola/.test("mundo hola"); // false
/mundo$/.test("hola mundo"); // true (termina en "mundo")

/\bcat\b/.test("el gato es un cat"); // true  (cat aislada)
/\bcat\b/.test("catarro");           // false (cat no está delimitada)
```

## 7. Cuantificadores

Indican **cuántas veces** puede repetirse el elemento anterior.

| Cuantificador | Significado |
|---------------|-------------|
| `*`   | 0 o más |
| `+`   | 1 o más |
| `?`   | 0 o 1 (opcional) |
| `{n}` | exactamente n |
| `{n,}`| n o más |
| `{n,m}`| entre n y m |

```js
/a+/.test("baaad");     // true (tres 'a')
/\d{3}/.test("1234");   // true (hay 3 dígitos)
/\d{2,4}/.test("1");    // false (necesita 2 a 4)
/colou?r/.test("color");  // true
/colou?r/.test("colour"); // true
```

### Codicia (greedy) vs perezosos (lazy)

Por defecto, los cuantificadores son **codiciosos**: toman la mayor cantidad posible.

```js
"aaaa".match(/a+/);   // ["aaaa"]
"aaaa".match(/a+?/);  // ["a"]  → el '?' lo hace perezoso (mínimo)
```

```js
"<b>hola</b>".match(/<.+>/);   // ["<b>hola</b>"]  (codicioso: traga todo)
"<b>hola</b>".match(/<.+?>/);  // ["<b>"]  (perezoso: se detiene pronto)
```

> Añade `?` tras un cuantificador para volverlo **perezoso**.

## 8. Grupos y alternancia

### Agrupar con `(...)`

Agrupa para aplicar cuantificadores o capturar.

```js
/(ab)+/.test("ababab"); // true (repetimos el grupo "ab")
```

### Alternancia con `|`

Funciona como un "OR" entre las opciones.

```js
/gato|perro/.test("tengo un perro"); // true
/(rojo|azul|verde)/.test("azul");    // true
```

> Ojo: `^gato|perro$` significa "empieza por gato" **O** "termina por perro", no "la cadena completa es gato o perro". Para eso: `^(gato|perro)$`.

---

## 9. Grupos de captura y no captura

### Captura `(...)`

Lo que coincida se guarda para reutilizarlo.

```js
const m = "2026-08-24".match(/(\d{4})-(\d{2})-(\d{2})/);
console.log(m[1]); // "2026"
console.log(m[2]); // "08"
console.log(m[3]); // "24"
```

### No captura `(?:...)`

Agrupa sin guardar (más eficiente cuando no necesitas el valor).

```js
/(?:https?):\/\//.test("https://x.com"); // true, pero no captura "https"
```

## 10. Símbolos especiales y escape

Estos caracteres tienen significado especial y deben escaparse con `\` si quieres usarlos literalmente:

```
. * + ? ^ $ { } ( ) [ ] | \ / 
```

```js
/\$/.test("precio: $5");  // true (el $ literal)
/\./.test("archivo.txt"); // true (el punto literal)
/\//.test("a/b");          // true (la barra literal)
```

---

## 11. Flags

Se colocan tras la `/` final. Los más importantes:

| Flag | Nombre | Efecto |
|------|--------|--------|
| `g`  | global | busca todas las coincidencias |
| `i`  | ignoreCase | ignora mayúsculas/minúsculas |
| `m`  | multiline | `^` y `$` actúan por línea |
| `s`  | dotAll | `.` también匹配 saltos de línea |
| `u`  | unicode | modo Unicode correcto |
| `y`  | sticky | ancla la búsqueda a `lastIndex` |

```js
/a/gi.test("ABCa");      // con gi: insensible + global
/^x/m.test("linea1\nxlinea2"); // true (x al inicio de la 2ª línea)
```

## 12. El objeto `RegExp` y sus métodos

### `RegExp.prototype.test(str)`

Devuelve `true/false`. Con flag `g`, avanza la propiedad `lastIndex`.

```js
/hola/.test("hola"); // true
```

### `RegExp.prototype.exec(str)`

Devuelve el objeto de coincidencia o `null`. Con `g`, va avanzando posición en cada llamada.

```js
const re = /\d+/g;
let m;
while ((m = re.exec("a1 b22 c333")) !== null) {
  console.log(m[0], "en índice", m.index);
}
// "1" en índice 1
// "22" en índice 5
// "333" en índice 10
```

---

## 13. Los métodos de `String`

### `String.prototype.match(regex)`

Con `g`: devuelve array de coincidencias. Sin `g`: devuelve el objeto match (con grupos).

```js
"a1b2".match(/\d/g); // ["1", "2"]
```

### `String.prototype.matchAll(regex)`

Devuelve un **iterador** con todos los detalles (incluye grupos). Requiere flag `g`.

```js
const iter = "a1 b2".matchAll(/(\w)(\d)/g);
for (const m of iter) console.log(m[1], m[2]);
```

### `String.prototype.replace(regex, reemplazo)`

```js
"hola mundo".replace(/mundo/, "amigo"); // "hola amigo"

// usar grupos en el reemplazo con $1, $2...
"2026-08-24".replace(/(\d{4})-(\d{2})-(\d{2})/, "$3/$2/$1");
// "24/08/2026"

// función de reemplazo (recibe el match completo y los grupos)
"5 gatos".replace(/(\d+)/, (_, n) => Number(n) * 2);
// "10 gatos"
```

### `String.prototype.search(regex)`

Devuelve el índice de la primera coincidencia, o `-1`.

```js
"abc".search(/b/); // 1
```

### `String.prototype.split(regex)`

```js
"uno, dos ; tres".split(/\s*[,;]\s*/); // ["uno", "dos", "tres"]
```

## 14. El objeto de coincidencia (match)

Un resultado de `exec`/`match` (sin `g`) es un array con propiedades extra:

```js
const m = "2026-08-24".match(/(\d{4})-(\d{2})-(\d{2})/);
m[0];      // "2026-08-24"  (coincidencia completa)
m[1];      // "2026"        (grupo 1)
m.index;   // 0             (posición en el texto)
m.input;   // "2026-08-24"  (texto original)
m.groups;  // undefined aquí (ver grupos nombrados abajo)
```

### Grupos nombrados `(?<nombre>...)`

```js
const m = "2026-08-24".match(/(?<año>\d{4})-(?<mes>\d{2})-(?<dia>\d{2})/);
console.log(m.groups.año);  // "2026"
console.log(m.groups.mes);  // "08"

// en replace:
"2026-08-24".replace(/(?<año>\d{4})/, "$<año>!"); // "2026!-08-24"
```

## 15. Backreferences

Dentro del patrón, puedes referirte a un grupo ya capturado con `\1`, `\2`… o `\k<nombre>`.

```js
// palabra repetida dos veces seguidas
/(¡w+) \1/.test("hola hola"); // true
/(¿w+) \1/.test("hola adios"); // false

// con nombre:
/(?<pal>\w+) \k<pal>/.test("hola hola"); // true
```

Utilidad: detectar palíndromos simples, duplicados, comillas equilibradas, etc.

## 16. Lookahead y lookbehind

Permiten **condicionar** la coincidencia sin incluir el texto en el match.

### Lookahead positivo `(?=...)`

Coincide si *a continuación* está el patrón, pero no lo consume.

```js
/\d(?=€)/.test("10€");  // true (hay dígito seguido de €)
/\d(?=€)/.test("10$");  // false
```

### Lookahead negativo `(?!...)`

Coincide solo si *no* está el patrón a continuación.

```js
/\d(?!€)/.test("10$"); // true
/\d(?!€)/.test("10€"); // false
```

### Lookbehind positivo `(?<=...)`

Comprueba lo que viene *antes* (ES2018+).

```js
/(?<=€)\d+/.test("€10"); // true (el dígito va tras €)
```

### Lookbehind negativo `(?<!...)`

```js
/(?<!€)\d+/.test("$10"); // true
```

## 17. Ejemplos prácticos

### Email simple (didáctico, no RFC completo)

```js
const email = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
email.test("a@b.com"); // true
email.test("a@b");     // false
```

### Validar un número de teléfono (España, simplificado)

```js
const tel = /^\+?34 ?[6-9]\d{2} ?\d{3} ?\d{3}$/;
tel.test("+34 612 345 678"); // true
```

### Extraer todas las URLs

```js
const urls = texto.match(/https?:\/\/[^\s]+/g);
```

### Convertir snake_case a camelCase

```js
"mi_variable_larga".replace(/_([a-z])/g, (_, c) => c.toUpperCase());
// "miVariableLarga"
```

### Contar palabras

```js
const palabras = "uno dos tres".match(/\b\w+\b/g); // ["uno","dos","tres"]
palabras.length; // 3
```

## 18. Errores comunes

1. **Olvidar escapar en `RegExp` (string):** usa `\\d`, no `\d`.
2. **Codicia no deseada:** `.*` traga demasiado; usa `.*?`.
3. **`test()` con flag `g` compartido:** `lastIndex` avanza entre llamadas y da falsos negativos. Recrea la regex o quita `g`.
4. **Confundir `[...]` con `(...)`:** corchetes = un carácter; paréntesis = agrupar/secuencia.
5. **Pensar que `.` matcha saltos de línea:** necesita flag `s`.
6. **Anclas mal agrupadas:** `^a|b$` ≠ `^(a|b)$`.
7. **Validar email/HTML con regex perfecta:** casi imposible; usa librerías para casos críticos.

---

## Resumen mental

- Una regex recorre el texto de izquierda a derecha buscando la primera posición válida.
- `[]` = un carácter entre varios; `()` = agrupar/capturar; `|` = o.
- Cuantificadores: `* + ? {n,m}`. Por defecto codiciosos; añade `?` para perezosos.
- Anclas `^ $ \b` marcan posición, no consumen texto.
- Flags `g i m s u y` cambian el comportamiento.
- `test`, `exec`, `match`, `matchAll`, `replace`, `search`, `split` son tus herramientas.
- Practica en consola: `node -e 'console.log(/patron/.test("texto"))'`.
