# Programar con JavaScript: de los datos a las soluciones

Esta es la portada de la segunda edición de los apuntes. El contenido fue reorganizado como un libro progresivo, con capítulos separados para cada tipo de dato, las colecciones, el control del programa y las aplicaciones integradoras.

Comenzá por el [índice general](00-indice.md).

El material utiliza la pirámide de Minto: cada capítulo presenta primero su conclusión central, luego las ideas que la sostienen y finalmente los detalles, casos límite, ejemplos y prácticas.

## Cómo estudiar para producir

En cada capítulo seguí este ciclo:

1. **Predecí** qué hará el ejemplo antes de ejecutarlo.
2. **Ejecutalo** con Node.js y observá el resultado real.
3. **Modificalo**: cambiá una entrada, una condición o una estructura.
4. **Aplicalo** a datos propios, aunque el problema sea pequeño.
5. **Explicalo** sin mirar el código. Si no podés explicarlo, todavía falta construir el modelo mental.

Podés crear un archivo `practica.js` y ejecutarlo así:

```bash
node practica.js
```

Cuando un ejemplo use módulos de Node.js, guardalo con extensión `.mjs` o agregá `"type": "module"` al `package.json`.

## Criterio de avance

No midas el progreso por páginas leídas. Avanzaste cuando podés:

- representar la entrada con una estructura adecuada;
- escribir una transformación clara;
- distinguir un caso esperado de un error excepcional;
- comprobar el resultado con ejemplos normales y casos límite;
- cambiar el programa sin romper todo lo anterior.

El objetivo final no es memorizar cada detalle de JavaScript, sino **resolver problemas de forma deliberada, legible y verificable**.
