# Recorrido visual de «Un React en miniatura»

Ámbito: `apuntes/mini-react-presentacion.html`.

La portada presenta las cuatro piezas que se construirán. Un fondo verde profundo y un título grande abren la clase; el resto del material usa superficies claras para leer código y proyectar con buena visibilidad.

Cada nivel empieza con un separador de fondo verde suave, un número de nivel y una pregunta. El cambio de escala ofrece una pausa entre conceptos. La posición del título y la franja inferior permiten mantener la orientación durante la explicación.

Las diapositivas de contenido usan tres recursos constantes: texto oscuro para explicar, verde para identificar conceptos y código, y una nota cálida para la idea que conviene recordar. El resaltado amarillo señala las líneas de código en las que se concentra cada explicación.

La relación entre el padre y los contadores aparece primero como diagrama, después como ranuras de memoria y finalmente como una demo. Motos, autos y camionetas conservan sus colores en esos tres momentos. En la demo, los contadores quedan junto a la memoria observable, de modo que se puede relacionar un clic con sus cambios de estado.

El ejemplo más largo de `App` se reparte en dos pasos: reloj y controles; contadores y resumen. La división permite aumentar la letra sin quitar el código necesario para explicar la composición.

Los ejemplos conservan el mismo tamaño de letra durante toda la explicación. La numeración de líneas permite señalar con precisión una instrucción durante la clase. Los comentarios y las llamadas más largas se distribuyen en varias líneas para reservar lugar a los números sin reducir la tipografía.

El cierre vuelve a las cuatro piezas iniciales. La identidad visual acompaña el recorrido sin depender de imágenes, fuentes descargadas, animaciones largas ni acceso a Internet.
