La capa de datos

De un archivo JSON a SQLite, de SQL a mano a Drizzle, de tu máquina a una base remota.

El archivo JSON ya no alcanza

  • 2 pedidos simultáneos pueden pisarse y perder un contacto
  • para traer uno solo, se lee el archivo entero
  • las reglas viven solo en nuestro código

Una base de datos resuelve eso

  • coordina los accesos simultáneos
  • encuentra datos sin recorrer todo
  • hace cumplir reglas sobre lo que se guarda

Es un programa especializado en guardar y consultar.

De servidor o embebida

PostgreSQL, MySQLotro proceso, a veces otra máquina. Se conecta por la red.
SQLiteuna librería dentro de tu programa. La base es un archivo.

Para desarrollar, SQLite es ideal: no hay nada que instalar ni configurar.

libSQL: una librería, 2 destinos

NULL es "no está". No es texto vacío ni cero.

La clave primaria

Una columna que identifica a cada fila sin repetirse.

Si al insertar no le damos valor, la base genera el siguiente número.

Se terminan los ids repetidos del archivo JSON.

Crear la tabla

NOT NULL: la columna tiene que tener valor.

UNIQUE: no se repite. Varias filas pueden tener NULL.

Estas reglas las controla la base. Ningún programa puede saltarlas.

Insertar

Columnas y valores, en el mismo orden. Lo que no se nombra queda en NULL. El id lo pone la base.

Consultar

SELECT elige columnas. * es todas.

WHERE filtra filas. ORDER BY las ordena.

Buscar por patrón

% reemplaza a cualquier cantidad de caracteres. Encuentra "Ana Díaz" y "Mariana Paz".

En SQLite, LIKE no distingue mayúsculas en letras sin tilde.

Modificar y borrar

Sin WHERE, afecta a todas las filas de la tabla.

Reemplazar

Modificar arma el SET

Lo que ganamos

  • la base genera los ids y ordena las escrituras
  • la búsqueda la hace la base
  • un correo repetido responde 409
  • las rutas no se enteraron del cambio

Los campos ausentes ahora llegan como null.

Los costos del SQL a mano

  • el SQL es texto: un error de tipeo aparece recién al ejecutar
  • los nombres de columna se repiten en cada función
  • el UPDATE de PATCH se arma pegando texto
  • la tabla vive en un texto dentro de crearTabla
  • IF NOT EXISTS no sirve para cambiar una tabla con datos

Qué es un ORM

Mapeo objeto-relacional: traduce entre tablas y filas, y objetos y funciones.

  • describe las tablas en código, en un solo lugar
  • arma las consultas con funciones, siempre con parámetros
  • convierte las filas en objetos

Qué es una migración

Un archivo SQL con un cambio puntual. Se numeran y se aplican en orden, una sola vez.

CREATE TABLE
0001_agregar_notas
ALTER TABLE
0002_...
la próxima

La base anota en una tabla propia cuáles ya aplicó. Cualquier copia se pone al día con las que le faltan.
