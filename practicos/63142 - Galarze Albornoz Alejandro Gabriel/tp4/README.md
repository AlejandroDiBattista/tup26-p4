# MiniCRM

MiniCRM desarrollado para el TP4 con Node.js, TypeScript, Express, Drizzle y SQLite.

## Como levantarlo

```bash
npm install
npm run dev
```

Luego abrir <http://localhost:3000>.

La base `minicrm.sqlite` se crea automaticamente al iniciar el servidor. La pantalla se encuentra en `public/MiniCRM.html` y consume la API REST del servidor.
